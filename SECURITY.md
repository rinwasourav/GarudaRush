# Security Policy

## Supported Versions

The following table lists which versions of GarudaRush are actively receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of GarudaRush seriously. If you discover a security vulnerability or security bug, please follow these steps:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email details of the vulnerability to: **souravrinwa0@gmail.com**
3. Include the following details:
   - Type of vulnerability (e.g., Unauthenticated API access, Command Injection, Memory leak)
   - Step-by-step proof of concept or instructions to reproduce
   - Potential impact of the issue

### Response Timeline
- **Acknowledgement**: Within 48 hours.
- **Triage & Patch**: Security fixes will be released via patch releases as quickly as possible.

## Disclaimer

GarudaRush is built for research, educational, and defense purposes under the Capstone project framework. Always obtain explicit authorization prior to monitoring or capturing packet telemetry on any network segment.
